# Work page previews

Add screenshots and optional video loops for portfolio projects.

## Screenshots (required for best results)

| File | Project |
|------|---------|
| `shelterlink.png` | ShelterLink (already added) |
| `carrick-plumbing.png` | Carrick Plumbing Co |
| `anchor-restaurant.png` | The Anchor Restaurant |
| `harbour-hair.png` | Harbour Hair Studio |

PNG, JPG, or WebP. Recommended size: **1200×750px** (16:10).

## Animated previews (optional — recommended over GIF)

Short **MP4 loops** (5–15 seconds, no audio) look sharper and load faster than GIFs:

| File | Project |
|------|---------|
| `carrick-plumbing-preview.mp4` | Carrick Plumbing Co |
| `anchor-restaurant-preview.mp4` | The Anchor Restaurant |
| `harbour-hair-preview.mp4` | Harbour Hair Studio |

Then uncomment `previewVideo` for that project in `lib/constants.ts`.

**Tip:** Record a screen capture of the live site scrolling, trim to ~10s, export as MP4.
