# Floodlights

Ryan picked this from three mockups (artboard "C. Floodlights"). Night-pitch green, chalk lines, one kit red, stadium type. The site should read as made by a person. The code-drawn game covers stay.

## Palette

```css
:root {
  --night: #0F2219; /* page background */
  --turf: #173528; /* panels and image frames */
  --turf-raised: #1D4031; /* hover and raised panels */
  --board: #0A1912; /* the price scoreboard only */
  --chalk: #EEF2EA; /* text and pitch lines */
  --chalk-soft: #C9D6CD; /* secondary text */
  --chalk-faint: #B7C6BC; /* captions */
  --line: rgba(238, 242, 234, 0.18); /* rules */
  --line-strong: rgba(238, 242, 234, 0.35);
  --cover-line: rgba(238, 242, 234, 0.5);
  --kit: #E5402F; /* the one accent */
  --kit-hover: #C9321F;
}
```

Kit red is the primary button, the highlighted player or ball in a cover, and one highlight per page.

## Type

- Big Shoulders Display 800 for h1, h2 and big numbers. Sentence case.
- Atkinson Hyperlegible 400 and 700 for everything else.
- Two families only. No monospace anywhere on studio pages.

## Banned

These are why the old site read as generated:

- All-caps labels or eyebrows above headings.
- Monospace labels.
- Strings joined with middle dots.
- Pill tech tags.
- Status dots.
- Corner arrows on cards.
- Underlines on single headline words.
- Grid-line or glow backgrounds.
- Noise textures.
- Fade-up on scroll.
- Identical card grids for everything.
- Two-part slogan headings ("Four steps, no surprises.").

## Keep

The code-drawn covers and their hover motion. They're the best thing on the site.
